# 📊 AWS Sentinel Hunting Queries (Hardened)

This document contains **validated and hardened KQL hunting queries** for AWS data ingested into Microsoft Sentinel.

Covered data sources:
- AWS CloudTrail
- AWS GuardDuty
- AWS VPC Flow Logs
- AWS CloudWatch

All queries are designed to be resilient to schema variation, missing fields, and multi-region ingestion.

---

## CloudTrail API Activity – Veeam & Trident

### Overview

Retrieves **CloudTrail API activity** generated by **Veeam** and **NetApp Trident**, resilient to:

- Missing or inconsistent `UserAgent` values
- EventSource-only identification
- Mixed service usage across regions

---

### KQL Query: Veeam and Trident API Activity (Hardened)

```kusto
let lookback = 30d;
AWSCloudTrail
| where TimeGenerated > ago(lookback)
| extend
    ua = tolower(tostring(UserAgent)),
    es = tolower(tostring(EventSource))
| extend Tool = case(
    ua has_any ("veeam", "veeam backup", "veeam-b&r"), "Veeam",
    ua has_any ("trident", "astra-trident", "netapp"), "Trident",
    es in (
        "fsx.amazonaws.com",
        "ec2.amazonaws.com",
        "ebs.amazonaws.com",
        "elasticfilesystem.amazonaws.com",
        "s3.amazonaws.com",
        "kms.amazonaws.com"
    ), "Trident",
    "Other"
)
| where Tool in ("Veeam", "Trident")
| project
    Tool,
    TimeGenerated,
    EventSource,
    EventName,
    UserIdentityArn,
    UserIdentityAccountId,
    SourceIpAddress,
    AWSRegion,
    UserAgent,
    RequestParameters,
    ResponseElements
| order by TimeGenerated desc
````

**Hardening notes**

* `tostring()` guards against null `UserAgent`
* EventSource fallback ensures Trident activity is captured
* Prevents silent drops when `UserAgent` is empty

## AWS GuardDuty Findings

### Overview

Returns **all GuardDuty findings** as surfaced in the AWS console, while handling:

* Non-EC2 resources
* Findings without network actions
* Multiple updates to the same finding

---

### KQL Query: All GuardDuty Findings (Hardened)

```kusto
AWSGuardDuty
| extend
    FindingId = tostring(Id),
    FindingType = tostring(ActivityType),
    FindingSeverity = tostring(Severity),
    FindingTitle = tostring(Title),
    FindingDescription = tostring(Description),
    AwsAccountId = tostring(AccountId),
    AwsRegion = tostring(Region),
    ResourceType = tostring(ResourceDetails.resourceType),
    InstanceId = tostring(ResourceDetails.instanceDetails.instanceId),
    ActionType = tostring(ServiceDetails.action.actionType),
    IsArchived = tostring(ServiceDetails.archived),
    CreatedAt = TimeCreated,
    UpdatedAt = TimeGenerated
| project
    UpdatedAt,
    CreatedAt,
    FindingId,
    FindingSeverity,
    FindingType,
    FindingTitle,
    AwsAccountId,
    AwsRegion,
    ResourceType,
    InstanceId,
    ActionType,
    IsArchived,
    Arn
| order by UpdatedAt desc
```

**Hardening notes**

* No assumptions that the resource is EC2
* Findings without instance details still return cleanly
* Archived state explicitly surfaced
* Handles repeated updates for the same finding ID

## AWS CloudTrail Events

### Overview

Baseline query for **all CloudTrail events**, hardened for:

* Inconsistent identity fields
* Federated and assumed-role sessions
* Missing optional fields

---

### KQL Query: All CloudTrail Events (Hardened)

```kusto
AWSCloudTrail
| project
    TimeGenerated,
    EventName,
    EventTypeName,
    EventSource,
    AWSRegion,
    UserIdentityAccountId,
    UserIdentityPrincipalid,
    UserIdentityArn,
    UserIdentityUserName,
    SessionIssuerUserName,
    SessionMfaAuthenticated,
    UserAgent,
    SourceIpAddress,
    AdditionalEventData,
    RequestParameters,
    ResponseElements
```

**Hardening notes**

* Includes both direct and assumed-role identity fields
* No filtering assumptions that would hide events
* Safe for data plane and control plane activity

## AWS Connector Heartbeat Monitoring

### Overview

Visualizes **daily ingestion health** for AWS connectors while handling:

* Zero-ingestion days
* Partial ingestion outages
* Connectors that temporarily stop producing events

---

### KQL Query: AWS Connector Heartbeat (Resilient)

```kusto
let Now = now();
let Lookback = 7d;

union
(
    range TimeGenerated from ago(Lookback) to Now step 1d
    | extend Legend = "AWSGuardDuty"
    | join kind=leftouter (
        AWSGuardDuty
        | summarize Count = count() by bin(TimeGenerated, 1d)
    ) on TimeGenerated
),
(
    range TimeGenerated from ago(Lookback) to Now step 1d
    | extend Legend = "AWSVPCFlow"
    | join kind=leftouter (
        AWSVPCFlow
        | summarize Count = count() by bin(TimeGenerated, 1d)
    ) on TimeGenerated
),
(
    range TimeGenerated from ago(Lookback) to Now step 1d
    | extend Legend = "AWSCloudTrail"
    | join kind=leftouter (
        AWSCloudTrail
        | summarize Count = count() by bin(TimeGenerated, 1d)
    ) on TimeGenerated
),
(
    range TimeGenerated from ago(Lookback) to Now step 1d
    | extend Legend = "AWSCloudWatch"
    | join kind=leftouter (
        AWSCloudWatch
        | summarize Count = count() by bin(TimeGenerated, 1d)
    ) on TimeGenerated
)
| extend Value = coalesce(Count, 0)
| project Time = TimeGenerated, Value, Legend
| render timechart
```

## CloudTrail Security-Focused Queries

### CloudTrail: IAM Changes (Access Modifications)

```kusto
let lookback = 14d;
AWSCloudTrail
| where TimeGenerated >= ago(lookback)
| where EventSource == "iam.amazonaws.com"
| where EventName in (
    "CreateUser","DeleteUser","UpdateUser",
    "CreateAccessKey","DeleteAccessKey","UpdateAccessKey",
    "AttachUserPolicy","DetachUserPolicy",
    "AttachRolePolicy","DetachRolePolicy",
    "PutUserPolicy","DeleteUserPolicy",
    "PutRolePolicy","DeleteRolePolicy",
    "CreatePolicy","DeletePolicy","CreatePolicyVersion","SetDefaultPolicyVersion",
    "UpdateAssumeRolePolicy"
)
| project
    TimeGenerated,
    EventName,
    UserIdentityAccountId,
    UserIdentityArn,
    UserIdentityUserName,
    SourceIpAddress,
    UserAgent,
    AWSRegion,
    RequestParameters,
    ResponseElements
| order by TimeGenerated desc
```

### CloudTrail: Root Account Usage

```kusto
let lookback = 90d;
AWSCloudTrail
| where TimeGenerated >= ago(lookback)
| extend IdentityType = tostring(parse_json(tostring(UserIdentity)).type)
| where IdentityType =~ "Root" or tostring(UserIdentityArn) has ":root"
| project
    TimeGenerated,
    EventName,
    EventSource,
    UserIdentityAccountId,
    UserIdentityArn,
    SourceIpAddress,
    UserAgent,
    AWSRegion,
    RequestParameters
| order by TimeGenerated desc
```

### CloudTrail: Console Logins and Failures

```kusto
let lookback = 30d;
AWSCloudTrail
| where TimeGenerated >= ago(lookback)
| where EventName == "ConsoleLogin"
| extend
    LoginResult = tostring(parse_json(tostring(ResponseElements)).ConsoleLogin),

    UserIdentityAccountId,
    UserIdentityArn,
    SourceIpAddress,
    AWSRegion,
    LoginResult,
    MFAUsed,
    UserAgent,
    AdditionalEventData
| order by TimeGenerated desc
```

## GuardDuty Severity-Focused Queries

### GuardDuty: High and Medium Severity Findings (Active)

```kusto
let lookback = 30d;
AWSGuardDuty
| where TimeGenerated >= ago(lookback)
| extend
    FindingId = tostring(Id),
    Severity = tostring(Severity),
    IsArchived = tostring(ServiceDetails.archived)
| where IsArchived != "true"
| where Severity in ("HIGH","MEDIUM")
| project
    TimeGenerated,
    TimeCreated,
    FindingId,
    Severity,
    ActivityType,
    Title,
    AccountId,
    Region,
    Arn
| order by TimeGenerated desc
```
