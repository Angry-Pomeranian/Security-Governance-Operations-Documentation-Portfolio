# Proofpoint Data Security Workbench Platform Overview

Proofpoint Data Security Workbench is a centralized platform used to investigate user activity and detect potential data security risks.

The platform aggregates telemetry from multiple sources and enables analysts to search, analyze, and investigate activities across the organization.

---

# Core Components

The platform includes the following core capabilities:

| Component | Purpose |
|---|---|
| Alerts | Monitor suspicious activities |
| Explorations | Query and analyze user activity |
| Detection Rules | Automate threat detection |
| Threat Library | Prebuilt security detections |
| Data Catalog | Monitor sensitive cloud files |
| Website Categorization | Classify browsing activity |
| Anomaly Detection | Identify behavioral deviations |

---

# Investigation Workflow

Security analysts typically investigate alerts using the following workflow:

1. Alert is generated by a detection rule
2. Analyst reviews alert details
3. Activity is analyzed using Explorations
4. Timeline investigation is performed
5. Files and data risks are reviewed in the Data Catalog
6. Incident is classified and resolved

---

# Data Sources

Data Security Workbench collects telemetry from multiple sources.

| Source | Description |
|---|---|
| Endpoint Telemetry | File activity and user behavior |
| CASB Data | Cloud storage and SaaS activity |
| Web Activity | Browsing behavior |
| File Activity | Uploads, downloads, and sharing |
