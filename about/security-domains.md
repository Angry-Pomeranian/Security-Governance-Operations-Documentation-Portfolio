# Security Domains Represented

## Identity and Access Security
- Multifactor authentication rollout and policy-driven authentication strengthening.
- Passwordless adoption patterns (Windows Hello for Business, passkey, Temporary Access Pass scenarios).
- Conditional Access policy design for user risk, device state, and application/session control.

## Security Operations and Detection Engineering
- Microsoft Sentinel onboarding and content development.
- Cloud and SaaS connector implementation for centralized monitoring.
- Hunting and workbook/reporting development to improve SOC triage and investigation.

## Cloud Security
- AWS log-source onboarding (CloudTrail, GuardDuty, VPC flow data, CloudWatch) into Sentinel pipelines.
- Telemetry transport architecture with S3/SQS-based ingestion workflows.
- Configuration validation and operational checks for connector health.

## Infrastructure and Endpoint Hardening
- CIS-aligned hardening guidance for Windows, RHEL, and major browsers.
- Enterprise policy enforcement for browser posture and extension governance.
- Device/security baseline alignment through MEM/Intune-linked configuration patterns.

## Security Integrations and Platform Engineering
- Security API integrations (including threat/intelligence and security tooling APIs).
- Connector and workbook templating for repeatable deployment.
- Operational scripts that standardize integration setup and reduce drift.

## DevSecOps and Automation
- Scripted operational tasks for security platform configuration.
- Infrastructure templates and runbook-oriented delivery.
- Security control implementation patterns embedded in deployment workflows.
