# About

## Background: 

I'm a security engineer and ISO with hands-on experience delivering practical controls across identity, endpoint, cloud, and SIEM/SOC workflows. My work spans Microsoft security platforms, AWS telemetry onboarding, CIS benchmark-aligned hardening, and automation-oriented integration engineering.

This portfolio documents real implementation patterns, not theoretical overviews, built to a standard where another engineer can pick it up and run with it.

---

## What This Portfolio Demonstrates: 

- **Identity-first security controls**: MFA rollout, passwordless authentication, Conditional Access policy design, and Entra ID governance.
- **Detection and visibility engineering**: Microsoft Sentinel connector deployment, KQL hunting content, workbook development, and cloud log source onboarding (AWS CloudTrail, GuardDuty, VPC Flow).
- **Endpoint and browser hardening**: CIS benchmark-aligned baselines for Windows Server, RHEL, and enterprise browsers; policy enforcement via Intune/MEM.
- **API and script-based automation**: Platform integrations, operational scripts, and Logic App workflows designed to reduce manual effort and improve response consistency.
- **Incident response**: Structured playbooks covering account compromise, ransomware, phishing, privileged access abuse, BEC, and network intrusion, aligned to ISO 27001:2022 and NIST SP 800-61.
